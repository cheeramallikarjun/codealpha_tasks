# Stock Portfolio Tracker

## Project Description
A Python-based Stock Portfolio Tracker that allows users to enter stock names and quantities, calculate individual and total investments, and save portfolio details to a text file.

## Features
- Enter multiple stock names and quantities
- Calculate individual investment value for each stock
- Calculate total portfolio investment
- Save portfolio details to a text file (`portfolio.txt`)
- Simple and user-friendly console interface

## Technologies Used
- Python
- File Handling (writing to text file)
- Loops and conditional statements
- User input handling

## How to Run
1. Make sure you have Python installed
2. Open terminal/command prompt
3. Run the command:
   ```bash
   python stock_tracker.py
